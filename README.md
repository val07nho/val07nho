¡Hola! Soy **Valeria Ramos**, estudiante de **8.º ciclo de Ingeniería Informática en la Universidad Ricardo Palma**, perteneciente al tercio superior.

Me interesa transformar datos en información que ayude a comprender problemas y tomar decisiones. He desarrollado proyectos académicos de **limpieza y transformación de datos, análisis exploratorio y clasificación con Machine Learning**, utilizando Python y SQL.
